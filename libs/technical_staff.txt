BEARING: https://www.igismap.com/formula-to-find-bearing-or-heading-angle-between-two-points-latitude-longitude/

Let ‘R’ be the radius of Earth,
‘L’ be the longitude,
‘θ’ be latitude,
‘β‘ be Bearing.

Bearing from point A to B, can be calculated as,

β = atan2(X,Y),

where, X and Y are two quantities and can be calculated as:

X = cos θb * sin ∆L (∆L = Longitude1 - Longitude2)

Y = cos θa * sin θb – sin θa * cos θb * cos ∆L

Lets us take an example to calculate bearing between the two different points with the formula:

Kansas City: 39.099912, -94.581213
St Louis: 38.627089, -90.200203
So X and Y can be calculated as,

X =  cos(38.627089) * sin(4.38101)

X  = 0.05967668696

And

Y = cos(39.099912) * sin(38.627089) – sin(39.099912) * cos(38.627089) * cos(4.38101)

Y = 0.77604737571 * 0.62424902378 – 0.6306746155 * 0.78122541965 * 0.99707812506

Y = -0.00681261948

***Convert θ into radians***

So as, β = atan2(X,Y) = atan2(0.05967668696, -0.00681261948) = 1.684463062558 radians

convert it into degree

           β = 96.51°

Manage Submodules using GIT
-------------------------------------------------
Submodules are external repositories that you link to your project.
Instead of duplicate their files, we link it to the original repository, hence changes we will do to them won't be reflected or pushed to the originating repository.

Here is how we add the ImgWindow library maintained by @slgoldberg in GitHub.

-- Remove the subfolder from your repository.
# 1. Deinitialize the submodule
git submodule deinit -f libs/imgui4xp/ImgWindow

# 2. Remove the git metadata entry
git rm -f libs/imgui4xp/ImgWindow

# 3. Clean up leftover directories and cache
rm -rf .git/modules/libs/imgui4xp/ImgWindow
rm -rf libs/imgui4xp/ImgWindow

git commit -m "Remove old ImgWindow submodule configuration"


Step 3: Add the Original Repository as the Submodule
Now add the original slgoldberg/ImgWindow repository at your correct path:
git submodule add https://github.com/slgoldberg/ImgWindow.git libs/imgui4xp/ImgWindow

Step 4: Initialize and Fetch All Files (Including Recursive Ones)
Pull down all the files and any nested submodules it depends on:
git submodule update --init --recursive

Step 5: Save the Changes in Your Project
git add .gitmodules libs/imgui4xp/ImgWindow
git commit -m "Add original slgoldberg/ImgWindow library as submodule"


# Only update the remote library to the latest commit:
git submodule sync libs/imgui4xp/ImgWindow
git submodule update --remote libs/imgui4xp/ImgWindow

Start cURL static library on Ubuntu 24.04
-------------------------------------------------



sudo add-apt-repository -y universe
sudo apt update

sudo apt install -y build-essential autoconf automake libtool pkg-config perl cmake curl tar

# Navigate to the folder you want to compile the libraries:
cd /mnt/staff01/programming/ubuntu/ub24.04/ubuntu_static_libs


1. Set Environment Variables and Folders

export REPO_DIR="/mnt/staff01/programming/ubuntu/ub24.04/ubuntu_static_libs"
export WORK_DIR="$REPO_DIR/work"
export INSTALL_PREFIX="$REPO_DIR/dist"

mkdir -p "$WORK_DIR" "$INSTALL_PREFIX" "$REPO_DIR/lib" "$REPO_DIR/include"



2. Build Static zlib
=====================
cd "$WORK_DIR"
curl -sSL https://github.com/madler/zlib/releases/download/v1.3.1/zlib-1.3.1.tar.gz | tar -xz
cd zlib-1.3.1

CFLAGS="-fPIC -O3" ./configure --static --prefix="${INSTALL_PREFIX}"
make -j$(nproc) install

ll ../../dist/lib/


3. Build Static OpenSSL 3.0 LTS
===============================
cd "$WORK_DIR"
curl -sSL https://github.com/openssl/openssl/releases/download/openssl-3.0.15/openssl-3.0.15.tar.gz | tar -xz
cd openssl-3.0.15

./config no-shared no-tests -fPIC --libdir=lib --prefix="${INSTALL_PREFIX}" --openssldir="${INSTALL_PREFIX}/ssl"
make -j$(nproc)
make install_sw

ll ../../dist/lib/


4. Build Static nghttp2
=======================
cd "$WORK_DIR"
curl -sSL https://github.com/nghttp2/nghttp2/releases/download/v1.63.0/nghttp2-1.63.0.tar.gz | tar -xz
cd nghttp2-1.63.0

./configure \
  --prefix="${INSTALL_PREFIX}" \
  --enable-lib-only \
  --enable-static \
  --disable-shared \
  CFLAGS="-fPIC -O3"

make -j$(nproc) install

ll ../../dist/lib/



5. Build Static cURL
====================
cd "$WORK_DIR"
curl -sSL https://curl.se/download/curl-8.10.1.tar.gz | tar -xz
cd curl-8.10.1

./configure \
  --prefix="${INSTALL_PREFIX}" \
  --with-openssl="${INSTALL_PREFIX}" \
  --with-zlib="${INSTALL_PREFIX}" \
  --with-nghttp2="${INSTALL_PREFIX}" \
  --enable-static \
  --disable-shared \
  --disable-ftp \
  --disable-ldap \
  --disable-ldaps \
  --disable-rtsp \
  --disable-dict \
  --disable-telnet \
  --disable-tftp \
  --disable-pop3 \
  --disable-imap \
  --disable-smb \
  --disable-gopher \
  --disable-mqtt \
  --without-nghttp3 \
  --without-ngtcp2 \
  --without-libssh2 \
  --without-libpsl \
  --without-libidn2 \
  --without-brotli \
  --without-zstd \
  --disable-file \
  --disable-ipfs \
  --disable-smtp \
  --disable-websockets \
  CPPFLAGS="-DOPENSSL_NO_ENGINE -I${INSTALL_PREFIX}/include" \
  LDFLAGS="-L${INSTALL_PREFIX}/lib -L${INSTALL_PREFIX}/lib64" \
  CFLAGS="-fPIC -O2"

make -j$(nproc) install

ll ../../dist/lib/


6. Update the repository: Copy Files to ubuntu_static_libs repository
=====================================================================
# Copy library archives
cp -f "${INSTALL_PREFIX}"/lib*/libcurl.a    "${REPO_DIR}/lib/"
cp -f "${INSTALL_PREFIX}"/lib*/libz.a       "${REPO_DIR}/lib/"
cp -f "${INSTALL_PREFIX}"/lib*/libssl.a     "${REPO_DIR}/lib/"
cp -f "${INSTALL_PREFIX}"/lib*/libcrypto.a  "${REPO_DIR}/lib/"
cp -f "${INSTALL_PREFIX}"/lib*/libnghttp2.a  "${REPO_DIR}/lib/"

# If libnghttp2 was not found, execute:
NGHTTP2_FILE=$(find "${INSTALL_PREFIX}" -name "libnghttp2*.a" | head -n 1)
cp -f "${NGHTTP2_FILE}" "${REPO_DIR}/lib/libnghttp2.a"

# Copy headers
cp -rf "${INSTALL_PREFIX}/include/curl"    "${REPO_DIR}/include/"
cp -rf "${INSTALL_PREFIX}/include/openssl" "${REPO_DIR}/include/"
cp -rf "${INSTALL_PREFIX}/include/nghttp2" "${REPO_DIR}/include/"
cp -f  "${INSTALL_PREFIX}/include/zlib.h"  "${REPO_DIR}/include/"
cp -f  "${INSTALL_PREFIX}/include/zconf.h" "${REPO_DIR}/include/"


7. Inspect the Generated Archives
=================================
ls -lh "${REPO_DIR}/lib"
file "${REPO_DIR}/lib/"*.a
